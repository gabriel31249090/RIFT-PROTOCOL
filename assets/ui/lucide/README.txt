Lucide icons, tag 0.468.0
Source: https://github.com/lucide-icons/lucide/tree/0.468.0/icons
License: ISC. Full upstream notice is in LICENSE.txt.

The original SVGs are preserved unchanged. The 48x48 PNGs are rasterized from
those SVGs using Apache Batik 1.18 with currentColor set to white. RIFT tints
the PNG alpha masks at runtime; no SVG library or JavaScript is required.

Icons used: play, crosshair, settings-2, users, trophy, box, eye, log-out,
arrow-left, chevron-left, chevron-right, minus, plus, check, save.
